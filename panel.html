Behavior

If calls or screen-share misbehave on Wayland, try “X11 / XWayland”.

Voice & video calls

Ruwa runs real Chromium, so calls use the same engine as Chrome.

Microphone, camera and notification access is granted automatically for WhatsApp origins.

On Wayland, screen-share goes through xdg-desktop-portal + PipeWire — keep your portal backend running.

Custom CSS

~/.config/ruwa/custom.css — reload the page to apply edits.

Premade mods

Bundled mods. They run inside WhatsApp Web and take effect on next launch.
